Setup

Three steps, no terminal.

1

Install the Live script

2

Turn it on in Ableton Live

  1. Restart Live if it was open while installing.
  2. Open Settings (Preferences) → Link, Tempo & MIDI.
  3. Under Control Surface, pick HellboyProd. Input and Output can stay on None.

3

Assistant

The built-in assistant uses your Anthropic API key. It is stored only on this computer.
